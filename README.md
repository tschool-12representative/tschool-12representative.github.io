# 三年級學生代表 — 新增頁面

這三個頁面延續官網（`index.html` / `style.css`）的設計語言：毛玻璃卡片、
圓角、柔和陰影、青綠→白→綠漸層背景，以及取自 logo 的三色。

## 檔案結構

| 檔案 | 說明 |
|------|------|
| `pages.css` | 三頁共用的頁面樣式（延伸自 `style.css`，需一起放） |
| `common.js` | 共用工具：CSV 解析、狀態對應表、徽章/標籤產生器 |
| `meetings.html` + `meetings.js` | 校務會議資訊（分頁頁籤、統計圖表、提案細節、通過比例、記錄連結） |
| `dashboard.html` + `dashboard.js` | 提案進度儀表板（類別/類型標籤 + 進度條 + 類別篩選） |
| `about.html` + `about.js` | 關於我們（大頭貼、簡歷、政見與狀態、連結） |

## 安裝

把以上所有檔案，連同原本的 `style.css`、`logo.png`、`favicon.ico`，放在
同一個資料夾（GitHub Pages 的網站根目錄）即可。頁面已互相連結，且會在
上方導覽標示目前頁面。

> 建議把首頁 `index.html` 裡「我們的工作！」三顆按鈕改成連到
> `meetings.html`、`dashboard.html`，「關於我們」連到 `about.html`。

## 資料怎麼管理（沿用首頁的 Google Sheet CSV 做法）

三個頁面**預設先用內建示範資料**顯示，讓你可以立刻預覽。要改成從
Google Sheet 讀取時，只要在對應 JS 檔頂端把 `CSV_URL` 填上你
「發布到網路 → CSV」的連結即可（做法同首頁）。讀取失敗時會自動退回
示範資料，不會出現空白頁。

### 校務會議（工作表建議欄位）
`會議編號 | 會議名稱 | 日期 | 代表 | 提案數 | 報告數 | 通過數 | 記錄連結 | 提案明細`
- 代表：以 `;` 分隔，格式 `姓名(年級)`，例：`王小明(三年級);林大同(二年級)`
- 提案明細：以 `||` 分隔多筆，每筆 `標題::類別::狀態::結果`

### 提案進度（工作表建議欄位）
`標題 | 說明 | 類別 | 類型 | 狀態 | 更新日期`
- 類別：學權 / 課務 / 生活 / 設備 / 其他
- 狀態：草擬 / 討論 / 提案 / 審議 / 執行 / 完結 / 取消 / 失敗

### 關於我們
最簡單的做法是**直接編輯 `about.js` 最上方的 `REPS`**（兩位代表的姓名、
大頭貼網址、簡歷、連結、政見）。若想用試算表管理，欄位說明見 `about.js`
內註解。政見狀態：預備 / 執行 / 完結 / 取消 / 失敗。

## 狀態顏色

| 狀態 | 用途 |
|------|------|
| 草擬 / 預備 | 灰 |
| 討論 | 黃 |
| 提案 | 青 |
| 審議 | 紫 |
| 執行 | 藍 |
| 完結 | 綠 |
| 取消 | 灰 |
| 失敗 | 紅 |

顏色定義都在 `pages.css` 最上方的 `:root`，要調色改那裡即可。
